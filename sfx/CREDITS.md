# Sound effects (sfx/)

Sound effects for the **Graveyard** module in Castle Danger Studio. Every file here is public domain (CC0 1.0): free for any use, commercial included, with no credit required. Credits are listed anyway, with thanks to the authors.

The files were converted to MP3 (and quiet tails trimmed on the hits); otherwise the sounds are unchanged. The [library terms](../TERMS.md) cover the community Heresy sounds in `sounds/`, not these files.

| Folder | Source | Author | License |
| --- | --- | --- | --- |
| Horror hits | [Horror Hit Soundpack 1](https://opengameart.org/content/horror-hit-soundpack-1) (OpenGameArt) | psychhead_ | CC0 |
| Dark ambiences | [Dark Ambiences](https://opengameart.org/content/dark-ambiences) (OpenGameArt) | Ogrebane | CC0 |
| Horror sound pack, Loops | [Horror Sound Pack](https://phlegmlee.itch.io/horror-sound-pack) (itch.io) | Phlegmlee | CC0 |

Horror hits naming: **Doom** = very low, **Dread** = low, **Shock** = mid, **Shriek** = high.

To add more: put CC0 sounds (WAV, MP3, OGG, FLAC or M4A) in a folder under `sfx/` and add a row above. Graveyard lists every audio file in this repo, named after the file and grouped by folder.
